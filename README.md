# AION 2 — Анализатор сборки v4mp

Персональный анализатор персонажа **v4mp** — Стрелок, Европа · Кромеде. Интерфейс и пояснения на русском языке. Технологии: React, Vite и Cloudflare Pages Functions.

## Что реализовано

- Загрузка публичного профиля v4mp из NCSOFT.
- Раздельное отображение уровня экипировки (GS / Item Level) и боевой мощи (CP).
- Отображение исходных групп характеристик `statList`, `statSecondList`, `statAdditionalList` без выдуманных и вычисленных бонусов.
- Просмотр экипировки, обликов, умений, карт Арканы и досок Даэваниона.
- Сопоставление умений Стрелка с PvE-ориентирами и опубликованной выборкой игроков Global.
- План улучшений по экипировке и умениям, с акцентом на добычу предметов в подземельях.
- Русские подписи интерфейса, подсказки, приоритеты, статусы и известные названия умений/предметов.
- Ссылки на официальный поиск персонажей NCSOFT, профиль Shugo.GG и профиль NotMeter.

## Источники и ограничения

Основной источник профиля — публичные JSON-точки NCSOFT:
- `/api/character/info`
- `/api/character/equipment`

Описание публичных точек и полей: [документация aion2_api](https://github.com/axsddlr/aion2_api/blob/main/docs/API.md). Это неофициальная документация; NCSOFT может менять API без предупреждения.

Профили:
- [Официальный поиск персонажей NCSOFT — Европа](https://aion2.plaync.com/en-us/characters/index?region=eu)
- [Профиль v4mp на Shugo.GG](https://shugo.gg/character/global/eu-kromede/v4mp)
- [Профиль v4mp на NotMeter](https://notmeter.com/?view=character&serverId=2316&characterId=6Q-UpcYBkUxRaoy_p3rjpM_kwjwWlBxUxx2BTNdYXHY%3D&name=v4mp&region=ww&globalRegion=eu)

Источники PvE-ориентиров:
- [Mobalytics — PvE-сборка Стрелка](https://mobalytics.gg/gamebase/guides/aion-2-ranger-pve-build)
- [AION2 Companion — Стрелок](https://aion2companion.com/builds/ranger/)
- [AION 2 META — Стрелок](https://aion2-meta.com/guides/ranger/)

Частота использования умения или предмета в опубликованной выборке не доказывает, что он сам по себе повышает урон. Приоритеты характеристик являются ориентиром и должны учитывать реальные значения персонажа, сопротивления цели и механику боя.

План добычи пока эвристический: он сопоставляет найденные предметы с опубликованными таблицами добычи. Шанс из таблицы может относиться к одному открытию контейнера/куба, а не ко всему прохождению подземелья. Анализатор не обещает гарантированное получение предмета и пока не рассчитывает математическое ожидание затрат или прирост урона каждого предмета.

Названия умений, классов, предметов, слотов экипировки, режимов и игровых систем переводятся единым словарём `src/lib/game-localization.js`. Словарь сверяется с русскими базами игровых названий: [dbaion2.ru](https://dbaion2.ru/classes/ranger/), [AION 2 Gaming Tools](https://aion2.gaming.tools/ru/classes/ranger) и [AION2Quest](https://aion2quest.pro/ru/skills/ranger). Для умений Стрелка используются названия русского клиента (например, «Меткий выстрел», «Прицельный выстрел», «Град из стрел», «Сила Байзела»). Если NCSOFT возвращает неизвестное название, оно может отображаться в исходном виде — неизвестный перевод не подставляется наугад. Английские названия сохраняются в исходных данных и ссылках для совместимости с внешними базами.

Отсутствующие значения не заменяются демонстрационными числами. Если один из основных запросов NCSOFT не отвечает, интерфейс показывает частичное состояние и предупреждение.

## Разработка и проверки

Требования: Node.js 22+.

```bash
npm install
npm test
npm run build
node --check functions/api/profile.js
node --check src/lib/character-data.js
npm audit
```

GitHub Actions запускает тесты, сборку production-версии, проверки синтаксиса и аудит зависимостей. Cloudflare Pages публикует каталог `dist` и функции из `functions/`.

## Технологии

- React 18
- Vite 6
- Cloudflare Pages Functions
- Встроенный тестовый модуль Node.js
- Лёгкие CSS-переходы и поддержка reduced motion

Проект остаётся лёгким для старых ПК и мобильных устройств.
